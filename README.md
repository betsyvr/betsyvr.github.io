## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic knowledge of JavaScript (for development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/betsyvr/betsyvr.github.io.git
   cd betsyvr.github.io
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser, or
   - Use a local development server:
     ```bash
     python -m http.server 8000
     # or with Node.js
     npx http-server
     ```

3. **View the site**
   - Local development: `http://localhost:8000`
   - Live version: `https://betsyvr.github.io`

## 💻 Development

### Making Changes

1. Edit the HTML, CSS, or JavaScript files
2. Open/refresh `index.html` in your browser to see changes
3. Push changes to the `main` branch to update the live site
